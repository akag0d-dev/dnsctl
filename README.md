# dnsctl

Утилита для быстрого переключения DNS и DoH (DNS-over-HTTPS) профилей в Windows без копания в панели управления и реестре.

Работает как в интерактивном меню, так и через аргументы командной строки (для скриптов и хоткеев).

## Возможности

- Интерактивное TUI-меню с управлением стрелками (`↑` / `↓`) или кнопками `W` / `S` (русская раскладка `Ц` / `Ы` тоже работает).
- Автоматический запрос прав администратора (UAC) при необходимости.
- Поддержка системного DoH в Windows: автоматически регистрирует DoH-шаблон сервера и включает шифрование.
- Проверка реального статуса DNS и DoH прямо из консоли.
- Простая структура профилей: конфиги лежат в папке `Config` в виде обычных `.json`.

## Скачать

Готовые релизы в разделе [Releases](https://github.com/akag0d-dev/dnsctl/releases):
- `dnsctl-win-x64.zip` — для 64-битной Windows.
- `dnsctl-win-x86.zip` — для 32-битной Windows.

В архиве только `dnsctl.exe` и папка `Config/` с готовыми профилями (Comss DNS, DNS AI).

## Использование

### Интерактивное меню

Просто запустите `dnsctl.exe`. Если запустить без аргументов, откроется меню:

```text
╔══════════════════════════════════════════════════════════╗
║                         DNSCTL CLI                       ║
║             управление DNS-профилями Windows             ║
╚══════════════════════════════════════════════════════════╝

  Адаптер   : Wi-Fi
  Конфиг    : comss_dns
  ────────────────────────────────────────────────────────
    [1] Выбрать конфиг                 загрузить DNS-профиль из Config
    [2] Очистить DNS                   вернуть автоматические настройки DHCP
    [3] Выбрать адаптер                сетевой интерфейс Windows
    [4] Применить выбранный конфиг     установить IPv4 и IPv6 DNS
    [5] Статус DNS / DoH               проверить активные DNS и шифрование
    [0] Выход                          закрыть DNSCTL
  ────────────────────────────────────────────────────────
  Навигация: ↑ / W и ↓ / S, выбор: Enter (или цифры 0-5)
```

### Командная строка

Для автоматизации или скриптов:

```powershell
# Показать список доступных конфигов
dnsctl profiles

# Список сетевых адаптеров
dnsctl list

# Проверить текущие DNS и активность DoH
dnsctl status
dnsctl status --adapter "Ethernet"

# Применить профиль
dnsctl apply comss_dns
dnsctl apply dns_ai --adapter "Wi-Fi"

# Сбросить DNS обратно на DHCP
dnsctl reset
dnsctl reset --adapter "Wi-Fi"
```

## Свои DNS-профили

Любой новый JSON-файл в папке `Config` сразу подхватывается программой:

```json
{
  "name": "Cloudflare DoH",
  "description": "Cloudflare DNS с шифрованием",
  "doh": "https://cloudflare-dns.com/dns-query",
  "ipv4": [
    "1.1.1.1",
    "1.0.0.1"
  ],
  "ipv6": [
    "2606:4700:4700::1111",
    "2606:4700:4700::1001"
  ]
}
```

Если DoH не нужен, поле `"doh"` можно удалить или оставить пустым.

## Важное примечание по Windows 11

В Windows 11 графический интерфейс («Параметры» -> «Сеть и Интернет» -> «Свойства адаптера») имеет баг: при программной установке DoH через Windows API интерфейс настроек иногда пишет «Без шифрования», даже когда системная служба `Dnscache` реально отправляет все запросы строго через HTTPS на порт 443.

Проверить реальный статус шифрования в системе можно через пункт меню **«5. Статус DNS / DoH»** (или команду `dnsctl status`).

## Сборка из исходников

Требуется .NET 10 SDK:

```powershell
# Сборка одного файла для x64
dotnet publish -c Release -r win-x64 --self-contained true

dotnet publish -c Release -r win-x86 --self-contained true
```
